Used: the shape of cepo's defer header. A stateless maker struct turns the
following lambda into the guard through operator+, a const reference holds that
temporary to the end of the scope, and the declared name is token-pasted from
__COUNTER__, falling back to __LINE__. The code follows CEPO's own conventions
and differs where C++11 requires it: the move constructor is defaulted rather
than deleted, and the lambda carries a trailing return type of -> void.
